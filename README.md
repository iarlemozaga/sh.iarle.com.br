## about

`iarle.sh` is a minimalist portfolio and technical journal focused on:

- linux
- infrastructure
- self-hosted services
- networking
- automation
- open source software

the visual identity is inspired by:

- unix terminals
- technical documentation
- old system manuals
- infrastructure dashboards
- editorial minimalism
